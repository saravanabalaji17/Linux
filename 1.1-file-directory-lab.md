# Linux File & Directory Lab Exercises

## Lab 1: Check Current Directory

**Objective:** Display your current working directory.

**Tasks:**

1. Open the terminal.
2. Display the current directory.
3. Verify you are in your home directory.

**Expected Command**

```bash
pwd
```

**Tasks**

## Lab 30: Mini Project

Create the following structure.

```
Company
│
├── HR
│     ├── employees.txt
│     └── salary.txt
│
├── IT
│     ├── servers.txt
│     └── inventory.txt
│
└── Backup
```

### Tasks

1. Create all directories.
2. Create all files.
3. Add sample data.
4. Display file contents.
5. Copy all files to Backup.
6. Rename `salary.txt` to `payroll.txt`.
7. Display the first 2 lines of `employees.txt`.
8. Display the last 2 lines of `servers.txt`.
9. Open `inventory.txt` using `less`.
10. Verify the final directory structure using `ls -R`.
